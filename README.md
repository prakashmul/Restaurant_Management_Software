# 🍽️ Restaurant Management Software

Full-featured restaurant management software with integrated POS, inventory control, order logs, and customer credit management.

---

## ✨ Features

* **💳 Point of Sale (POS):** Fast and intuitive checkout system for table management, order taking, and bill splitting.
* **📦 Inventory Management:** Real-time tracking of ingredients, stock levels, low-stock alerts, and automated updates upon order completion.
* **📜 Order History:** Comprehensive logging of past orders, filtering by date/time, status tracking, and printable receipts.
* **📖 Credit Ledger Details:** Dedicated ledger for managing customer credit accounts, tracking balances, and logging payments.

---

## 🛠️ Tech Stack

* **Frontend:** [React]
* **Backend:** [Node.js, Express, TypeScript]
* **Database:** [MongoDB]
* **UI/Styling:** [Tailwind CSS]
